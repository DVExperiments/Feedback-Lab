# Feedback Lab — Classroom Website v0.4

Feedback Lab is a standalone educational web application for cybernetics and adaptive intervention design. It is **not hosted within Ripple Map** and requires no connection to that repository.

## Files
- `index.html` — welcome / instructions / import guidance.
- `lab.html` — guided five-stage interactive workspace and simulations.
- `favicon.svg` — site icon.

## Publish on GitHub Pages
Create a separate repository for Feedback Lab. Upload these three files to the **repository root**. In Settings → Pages, select **Deploy from a branch**, `main` and `/ (root)`. The homepage will be `https://YOUR-USERNAME.github.io/YOUR-REPO/` and workspace at `/lab.html`.

## Import from Ripple Map
Export **classroom project JSON** from Ripple Map (not a map image/SVG). On the Feedback Lab workspace choose **Import Ripple Map JSON**, select the file, and check the populated intervention fields. Imports are local to the browser; there is **no link** or shared repository.

## Student data
The workspace uses browser local storage and can export project JSON. Students sharing computers should export their projects and clear browser data if needed.

## Caveat
The four models are simplified instructional demonstrations, not calibrated predictions of a real context.
