How to import your Ripple Map project

Feedback Lab is a separate application. You can transfer your intervention by downloading a JSON file from Ripple Map and importing that file here. No account connection or live integration is needed.

First, export your work

  1. In the Ripple Map classroom activity, complete your system map and Intervention V1.
  2. Use the Export JSON option to save your classroom project file to your device.
  3. Keep the downloaded .json file somewhere you can find it (usually Downloads).
Export the project JSON, not an image or SVG of the map. Images cannot carry your intervention answers into Feedback Lab.

Then, import it here

  1. Select Open workspace or Start the activity on this site.
  2. Click Import Ripple Map JSON at the top of the workspace.
  3. Choose the downloaded JSON file. Your system, friction point and V1 details will populate the first step.
  4. Check the imported information, select a system model, and continue.

If you haven't used Ripple Map, you can still start from scratch or load the worked example.

Questions before you start

Do I need a Ripple Map file?

No. It's optional. Enter your V1 intervention manually or load the worked maintenance example instead.

What exactly imports from Ripple Map?

Compatible classroom JSON projects transfer the system name, friction description, intervention name and intervention idea. The interactive node map itself is not recreated inside Feedback Lab.

Will the simulation predict what happens in real life?

No. Its simplified, illustrative models help you explore feedback, delayed information, triggering rules and possible trade-offs. Real interventions should be tested with real-world observations.

Where is my work stored?

Progress is saved in this browser using local storage, not uploaded to a server. Export a Feedback Lab project JSON if you want a portable backup or to continue on another device. Shared computers can expose locally saved work to later users of the same browser profile.

Can I change my design after testing?

Yes. Return to any stage, edit the loop or intervention, and run the same disruption again. That's the point of the activity.
